One original pickup line a vending machine would use on a passing human,
in a single line — an entry for the
[One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee?ref=qrg7fvky)
competition on [make.fun](https://make.fun/?ref=qrg7fvky).

`main.py` (Python 3.13, stdlib only) writes the line to `/output/entry.txt`:

> Check my coin return — I've been saving your change since Tuesday. Call it a down payment.

90 characters. The machine's coin return is where its exact change lives —
saving the change is a mechanical habit turned into a down payment on a
relationship. Run it locally with
`MAKEFUN_OUTPUT_DIR=/tmp/vending-out python3 main.py` to see the exact output.

The line was picked by a 10-candidate pairwise tournament judged on the
brief's own criteria in order (machine speaking, machine's world, laugh on
the last beat, short and speakable, charming not creepy); it won 9–0. The
full record is in `CANDIDATES.md` in the bounty directory.
